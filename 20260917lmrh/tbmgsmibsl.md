# 【健康科普】为“不安”的小动作松绑——儿童抽动症家庭护理手册

> 更新时间：2026-09-17 (UTC+8)

**点击上方蓝字关注我们**

在我们身边，有这样一群孩子，他们有时会不自主地眨眼、耸肩、吸鼻子，或者时不时地发出清嗓子声。许多家长会误以为这是孩子的不良习惯，甚至加以责备。殊不知，这些行为背后，可能隐藏着一个需要被理解和关爱的名字——儿童抽动障碍，简称儿童抽动症。

**一、什么是儿童抽动症？**

儿童抽动症是一种起病于儿童时期的神经发育障碍，其核心特征表现是：不自主、无目的、快速、重复的肌肉抽动或发声，分为运动性抽搐和发声性抽动。

运动性抽动：通常从头面部开始，如眨眼、挤眉、吸鼻子、咧嘴、摇头、耸肩、甩手等。

发声性抽动：如清嗓子、干咳、发出“啊啊”、“吭吭”等怪声，少数可能出现重复性言语。

关键认知：这些表现并非是孩子故意为之，无法单靠意志力控制。家长的指责和惩罚不仅无效，反而可能加重症状，造成二次心理伤害。

**二、家庭护理的“四要”与“四不要”：爱与理解的实践课**

【“四要”原则】

1.  要“视而不见”，坦然接纳

当孩子出现抽动动作时，最好的反应就是“忽略”。不提醒，不过度关注，更不要模仿或取笑。父母的坦然接纳，是孩子建立自信、减轻焦虑的第一剂良药。

2.  要营造轻松、稳定的家庭氛围

压力与紧张是抽动症的“催化剂”。建立规律作息、保证充足睡眠，打造一个民主、温暖的家庭环境。减少对学业的过度施压，多关注孩子的情绪和兴趣。

3.  要保证均衡营养与适度运动

避免过多摄入含咖啡因、添加剂的食物（如巧克力、可乐、零食）和辛辣刺激物。鼓励孩子多进行户外活动，如跑步、跳绳、打球等，有助于缓解神经紧张，释放能量。

4.  要真诚沟通，成为孩子的盟友

耐心倾听孩子在学校或社交中的困扰。当孩子因抽动被同伴嘲笑时，要给予情感支持，并教他如何应对，努力成为孩子面对外界的力量后盾。

【“四不要”禁忌】

1.  不要指责和过分关注

反复提醒只会加深孩子的紧张与自责，容易形成“越关注越严重”的循环。

2.  不过度使用电子产品

长时间接触电子产品，其闪烁的画面与高强度刺激易加重抽动表现。

3.  不盲信偏方与“特效疗法”

抽动症的病因复杂，与遗传、神经调节等多种因素有关。请务必在专业医生指导下干预，不轻信缺乏科学依据的方案。

4.  不讳疾忌医，科学应对

如果抽动症状频繁、严重影响到孩子的学习、生活和社交，请务必带孩子前往儿童专科门诊，接受专业评估与干预（如行为训练或药物治疗）。

**三、校园支持：营造理解的环境**

学校是孩子的第二成长空间，建议家长主动与老师沟通，让老师了解孩子的情况，获得老师的理解与支持。共同做到在课堂上适度包容孩子的抽动表现；引导同学友好相处，抵制嘲笑与霸凌。我们呼吁更多人能了解儿童抽动症。它不是可怕的疾病，只是孩子成长道路上遇到的一道小关卡，让我们用理解和关爱，为那些“不安”的小动作温柔松绑。
